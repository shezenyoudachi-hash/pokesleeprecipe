# 料理図鑑（ポケモンスリープ）

SwiftUI 製のポケスリ料理レシピ図鑑アプリです。iOS 17 以降 / Xcode 16 以降。

## 開き方
1. `PokeSleepRecipes.xcodeproj` をダブルクリック
2. Signing & Capabilities で自分の Team を選ぶ（Bundle ID は `com.example.PokeSleepRecipes` なので必要に応じて変更）
3. シミュレータか実機を選んで ▶︎

## できること
- カレー・シチュー / サラダ / デザート・ドリンクの全78品（ごちゃまぜ系は除外）
- 料理名・食材名で検索、食材で絞り込み（選んだ食材をすべて使うレシピ）
- 鍋の容量で絞り込み（入りきるレシピだけ表示）
- 図鑑順 / エナジー順 / 食材数順 / 名前順の並び替え
- 詳細画面で食材・レシピボーナス・レシピLv1〜70のエナジーとグラフ
- レシピごとのLvとお気に入りを端末に保存

## ファイル構成
| ファイル | 役割 |
|---|---|
| `recipes.json` | 食材19種・料理78品のデータ（2026年10月時点） |
| `Models.swift` | 食材・レシピ・カテゴリ、レシピLv倍率表 |
| `RecipeStore.swift` | データ読込、エナジー計算、お気に入り・Lvの保存 |
| `RecipeListView.swift` | 一覧（カテゴリ切替・検索・並び替え） |
| `FilterSheet.swift` | 食材・鍋容量の絞り込み |
| `RecipeDetailView.swift` | 詳細（食材・エナジー・グラフ） |

## エナジー計算
`食材エナジー合計 × レシピボーナス × レシピLv倍率`（四捨五入）。
フィールドボーナス・大成功・イベント補正は含みません。

## データの更新
新レシピが追加されたら `recipes.json` の `recipes` に追記するだけで反映されます。
新しい食材は `ingredients` に `id / name / emoji / energy` を追加してください。
データは有志のオープンソースツール SleepAPI を元に作成し、日本語名は攻略サイトで照合しています。
